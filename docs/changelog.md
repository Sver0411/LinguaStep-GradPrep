## v0.18.1 例句展示与中外文朗读（2026-10-24）

- 揭示后的日语、英语单词下始终展示一条例句及中文译文，简洁模式也显示；内置 2560 组词的两种语言均已有完整例句和译文。
- 自动朗读首个表达时依次播放“单词 → 单词中文释义 → 外语例句 → 例句中文译文”；第二个表达播放“单词 → 外语例句 → 例句中文译文”，不重复单词中文释义。支持日语/英语优先、同时揭示和单语模式。
- 例句旁提供一键重播“外语例句＋中文译文”。自动朗读关闭时仍可手动播放。选择题作答前隐藏例句，提交后在反馈中显示并朗读。
- 预加载单词、例句和译文，客户端按最多 3 个并发排队，避免两种语言合计 7 段音频同时请求触发语音服务限流；换词或退出会停止当前朗读。
- 自行导入的词书若缺例句译文，会如实显示暂无译文，不把单词释义冒充整句翻译。

验证：24 个测试文件、176 项测试通过；类型检查与 Next.js/Vercel、Vinext 生产构建通过。已实测中文例句接口返回 MP3。

## v0.18.0 五词揭示与客观练习（2026-10-24）

- 保留原来的中文提示、分步/同时揭示和发音。每批先熟悉 5 组词，揭示完直接进入选择题；移除“认识 / 模糊 / 不认识”和学习页“已熟知”手动跳过评价。
- 日英混合练习支持日语选英语、英语选日语，后续练习轮换方向；单语模式练对应中文意思。作答前隐藏中文、例句和答案读音提示，选项从现有词库取出、去重并打乱；无法生成有效四选一时不编造答案，也不计为通过。
- 本轮答对的词退出当前练习池；答错或提前查看答案的词保留，不再回到揭示。保留 2 组时就揭示 3 组新词，补满 5 组继续练习；新词不足时按实际剩余数量练习。
- 去掉轮次总结确认页。每批最后一题点“继续学习”，直接进入下一批新词揭示或保留词练习；本次全部通过后才显示最终完成页。
- 词汇客观练习接入 `ts-fsrs@5.4.2` 的 FSRS-6 调度：答错/看答案记 Again，答对记 Good，目标保留率 90%，使用默认模型参数。答题速度只记录耗时，不用于推断 Hard/Easy。
- “本轮通过”按本次答案判定；长期“已掌握”另外要求连续至少 3 次间隔不小于 24 小时的成功、稳定性至少 21 天，混合模式还要求双向成功。后者是产品的保守展示规则，并非 FSRS 官方分级或考试能力认证。
- 每次答案保存到复习历史、练习记录及错题本；同词同模式同日重试不会重复增加每日学词数。旧自评记录保留，首次客观测试建立独立 FSRS 状态，不把自评补造成真实答题记录。隔日选择正确率与旧自评回忆率分开统计。

算法依据与实现边界见[间隔重复算法](spaced-repetition.md)。

验证：24 个测试文件共 172 项通过；最终桌面/手机循环、旧错词不再揭示、跳过中间总结的回归通过；类型检查与两种生产构建通过。ESLint 无错误，保留 10 条旧 Hook 依赖警告。已在本地浏览器走查桌面及 400px 手机布局，未部署公开站点。

## v0.17.1 朗读顺序调整（2026-10-23）

- 只有第一个揭示的外语单词后朗读中文释义，第二个只读外语。同时揭示按“第一个外语 → 中文 → 第二个外语”播放；单语模式仍为“外语 → 中文”。适用于日语优先、英语优先和随机顺序。

## v0.17.0 使用体验修复（2026-10-23）

- 纠正 800 道中学英语题的等级，统一归入“基础英语”；教辅和公开练习不再计作官方历年题。隔离 1 道选项重复的 OCR 题，补齐英语阅读后续题的原文。
- 修复手机单语词卡提前泄露答案；日语、英语、日英混合模式均使用一组“认识 / 模糊 / 不认识”，混合模式一次评价整张卡。保留各学习模式自己的复习记录，修复同轮生词重现后不能继续评价的问题。
- 使用免 Key 的 Microsoft Edge 在线神经语音，默认揭示后立刻朗读外语，再接中文意思；卡片加载时并行准备两段音频，复用播放器，减少衔接等待。已移除系统机械音和旧词典音源回退。
- 词书及其收藏可“加入学习”，接入今日新词与间隔复习；重复加入识别已有词，保留学习进度。
- 新增短句听辨、听写、语法填空、新语境阅读入口，每轮最多 5 题，优先未见题，结果接入错题本；听写和填空在错题复练时仍保留输入作答，听力题保留音频。
- 手机设置补齐 JSON 备份、恢复确认和最近导出时间，明确当前浏览器存储与手动跨设备迁移方式。
- 增加一个主目标、每日 10/20/30 分钟预算和可选考试日期；计划先处理复习，根据近期完成耗时估算任务量，展示调整原因。重算计划不会把之前的完成次数算成新任务已完成。
- 统计增加 7/30 天延迟自评回忆、题目首次作答正确率、分项表现与反复出错内容，并可进入对应练习。历史记录不足时显示无数据，不编造回忆历史。

本轮仍使用原有 SM-2 衍生调度器；新增训练复用现有材料，并不代表已经覆盖完整考试题型或完成所有题目的专业难度校准。实现记录见[使用体验审查与修复状态](../review/使用体验审查-2026-10-23.md)。
