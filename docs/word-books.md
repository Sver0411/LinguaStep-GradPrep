# 词书

[项目首页](../README.md) · [内容来源](vocabulary-sources.md)

当前提供红宝书、绿宝书各 N1–N5，共十册，12,905 个去重词、24,137 条册内引用。书架以封面选册；N4/N5 等合册沿用原封面，以等级标记区分。

单词页默认打开上次选择的词书，通过“换书”按钮返回书架。单词页默认收起词表；点击封面或“浏览单词”后，可连续滚动全册、搜索日语/假名/中文/英语、勾选指定词汇背诵。语言与顺序选项位于可展开的“学习设置”。顺序学习按册内顺序，随机学习先打乱候选词；勾选学习会保留全部所选词，不受自动选词的每轮数量截断。同一日语词形及读音在不同册中使用同一进度 ID；不同语言模式各自保留状态。

红宝书按文字卡组原始词条顺序；绿宝书按课号、单元内五十音排序，已比对本地书籍的开头词条。公开卡组与用户 PDF 可能有版本差异，不承诺逐页一致。缺少有效词头、读音或中文释义的 136 条原始记录未进入学习；相同词跨册与册内去重，因此册内数量可能少于原始卡片数。

旧内置词汇已经停用，词汇改用新词书。个人学习历史、收藏键及备份继续保留；不再有效的旧词错题归档。日语单词优先播放已提取 MP3，其他朗读继续使用既有同源 TTS。卡组音频为其作者提供的 Azure 神经语音，不能称为真人录音。学习卡不额外区分例句的整理来源。

音频保存在部署机器的独立目录，通过 `LINGUASTEP_AUDIO_DIR` 指定；本地默认 `work/book-audio`。不将 250 MB 的音频放入 Git。缺文件时播放器回退到原神经语音。

## 中文释义整理 · v0.20.0

对全部 12,905 条释义做了格式和异常筛查，复核长释义、括号注解及可疑词典残片，精简或修正 1,248 条。优先保留常用、易懂的中文义，必要时保留多个义项；按词形和读音区分“生物／せいぶつ”与“生物／なまもの”等同形词。未按字符硬截断，不把词典中的日文说明或例句片段当作词义。

原释义和修改后的释义存于 [word-meaning-review.json](../data/word-meaning-review.json)，以稳定词条 ID 对应。修改只影响中文释义；书目归属、顺序、词头、读音、例句、音频和学习进度 ID 均保留。

`build-word-books.py` 在合并来源和既有编辑修订之后自动应用该清单。也可对生成文件单独运行 `python3 scripts/compact-book-meanings.py`，重复运行结果一致。若源释义发生变化，脚本要求重新审核，不盲目覆盖新来源。
