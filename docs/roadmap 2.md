# 开发路线图

## 第一阶段：本地学习闭环（已完成）

首页、词卡、语法、测试、错题、收藏、统计、IndexedDB v1 与响应式界面。

## 第二阶段：长期复习系统（已完成）

IndexedDB v2 无损迁移、三模式复习、每日计划、300 组词、50 个语法、15 组对比、来源/难度测试、错题生命周期、完整统计、设置和自动化测试。

## 第三阶段：安全可控 AI（已完成）

- DeepSeek v4 Fast/Quality 模型和 OpenAI-compatible JSON API
- 服务器 Key + 生产代理令牌、BYOK 会话/设备模式
- 词卡、日语/英语语法、日英语义对比和四选一题生成
- 错题中文解释、缓存和重新生成
- Zod、业务规则、重复/引用检查、修复与可选质量复核
- 自动/临时保存、撤销、历史、用量、内容删除和反馈
- 超时、重试、取消、并发、去重、限流、离线降级与中文错误
- IndexedDB v3 原地升级、安全文档、Mock 单元/接口/组件/工作流测试

## v0.4：学习动线精简（已完成）

- 单一“继续今日学习”入口与统一下一步判断
- 到期复习 → 新词 → 语法 → 测试 → 错题巩固的连续完成动线
- 单词学习/词库浏览分层、今日语法优先、一键测试预设
- 错题连续队列与默认收起的筛选、管理和危险操作
- 桌面端“学习 / 复习 / 工具”导航分组，AI 降为高级内容工具
- 保留全部历史数据、间隔重复、AI 内容、旧路由和本地离线能力

## v0.5：内容扩展与专项测试（已完成）

- 内置日英对应词扩充到 6000 组，并保留原 300 组人工精编词优先级
- 日英语法对比扩充到 137 组，覆盖基础到 N1 的高频语义关系
- 新增日英语法对比混合测试，同一轮按不同对比项去重抽题
- AI 语法默认批量新增 10 条，可在设置中调整为 10–30 条
- 错题卡默认只展示练习所需信息，答案、解析、历史与管理集中收起

## 后续候选（未承诺）

账号与多设备同步、导入导出、发音、语音识别、自由输入翻译与批改、完整 FSRS、PWA、自定义内容编辑器、管理员后台和社交功能。

这些能力不会以半成品进入正式版本；每项需要单独的数据、隐私、安全和迁移设计。
