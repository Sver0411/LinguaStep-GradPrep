# 开发路线图

## 第一阶段：本地学习闭环（已完成）

- 首页、日英词卡、语法、混合测试、错题、收藏和基础统计
- 100 组词、14 个日语语法、6 个英语语法
- IndexedDB v1、localStorage 设置、内存降级
- 响应式主题、专注模式和核心单元测试

## 第二阶段：长期复习系统（已完成）

- IndexedDB v2 与无损、幂等的 v1 → v2 迁移
- 可解释的 SM-2 衍生调度、到期/逾期队列和三模式独立进度
- 每日本地计划、周末调整、错题优先、未完成任务接续与手动重算
- 300 组词、35 个日语语法、15 个英语语法、15 组日英对比
- 全局内容搜索以及等级、频率、状态、收藏、错题和到期筛选
- 日语、英语、混合测试及今日/7 天/错题/收藏/到期来源
- 错题四阶段生命周期、历史、独立收藏与人工管理
- 收藏搜索、专项入口和批量取消
- 13 项统计概览、7/30 天趋势、语言与掌握分布
- 设置、可访问性、组件测试、数据库升级测试和关键工作流集成测试

## 第三阶段：DeepSeek 辅助内容（规划）

- 生成词卡、例句、语法讲解、对比和选择题
- 针对错题生成个性化中文解释
- 生产环境使用后端代理；个人本地测试可选仅会话 API Key
- 生成结果先进入草稿，经过 schema、去重、难度和语言质量检查后由用户确认保存
- 记录来源和版本，不自动覆盖人工精选内容

详见 [DeepSeek 接入方案](deepseek-integration.md)。

## 后续候选（未承诺）

- 账号与多设备同步、冲突解决、删除标记和数据加密
- 导入导出、发音、拼写、自由输入翻译与水平测试
- 完整 FSRS、PWA、管理员后台和自定义内容编辑器

这些能力不会以隐式半成品进入当前版本；每项都需要单独的数据模型、隐私和迁移设计。
