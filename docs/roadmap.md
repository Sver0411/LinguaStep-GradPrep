# 开发路线图

## 第一阶段：本地学习闭环（已完成）

- 今日学习概览和默认任务
- 100 组真实日英对应词
- 14 个日语语法、6 个英语语法，每项 5 道练习
- 日英对照单词卡、完整/简洁显示、两种揭示模式
- 日英混合选择题、逐题解析和测试结果
- 错题优先级、连续答对 3 次退出活跃列表
- 单词与语法收藏、基础学习统计
- IndexedDB 学习数据、localStorage 设置、内存降级
- 浅色/深色/系统主题、桌面和手机响应式、专注模式
- 核心领域和仓库单元测试

## 第二阶段：复习系统与内容扩充

计划按以下顺序推进：

1. 将基础 `ReviewSchedule` 升级为正式 FSRS，实现到期队列和自动每日计划。
2. 增加单独日语/英语单词模式，以及英语语法独立入口。
3. 增加搜索、等级、掌握度和收藏筛选。
4. 扩充至约 300 组词和 50 个语法点，建立内容校验脚本。
5. 增加最近 7 天/30 天趋势、正确率和复习负载图表。
6. 新增云端 `LearningRepository`、账号认证、合并策略和多设备同步。

第二阶段仍保持领域逻辑与 UI 解耦，避免复习算法散落在组件中。

## 第三阶段：DeepSeek 辅助内容

- 生成单词卡与例句
- 生成语法讲解和对比
- 生成选择题与合理干扰项
- 针对错题生成个性化中文解释
- 支持“仅本次使用”与“校验后保存”
- 生产环境后端代理；个人本地环境可选 API Key 测试模式

AI 生成内容必须经过结构校验、去重、难度与语言范围检查；默认不得直接覆盖人工精选内容。

## 明确不在当前范围

发音、拼写、自由输入翻译、首次水平测试、管理员后台、CSV/JSON 导入导出、Docker 和完整 PWA 均不进入第一阶段。
