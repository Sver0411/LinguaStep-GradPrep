# 后续方向

[项目首页](../README.md) · [文档目录](README.md) · [版本记录](changelog.md)

## 当前已提供

- 日语、英语、日英对照三种学习模式；每批 5 组先揭示、后练习。
- 例句与中文译文、在线自然语音、双语重播。
- 客观词汇答题使用 FSRS-6，接入每日计划、错题和学习统计。
- 词书查阅、收藏与加入学习，语法对比及听辨/听写/填空/阅读训练。
- 桌面与移动端布局，本地 IndexedDB 记录及手动 JSON 备份恢复。

早期阶段、内容数量变化和具体修复不再在本页重复展开，统一保留到[版本记录](changelog.md)。

## 优先候选

| 方向 | 希望解决的问题 |
| --- | --- |
| 内容校准 | 对应真实考试目标核对题目难度、来源、解析和覆盖 |
| 材料补齐 | 改善词书例句译文与缺失字段，减少学习入口断点 |
| 复习效果 | 积累真实隔日答题记录，评估默认 FSRS 参数，再考虑个人优化 |
| 移动端可靠性 | 继续验证真实设备的音频、存储、布局和备份恢复 |

这些方向尚无承诺的发布日期，具体范围以实际版本记录为准。

## 尚未提供

账号与自动云同步、语音识别、自由作文与翻译批改、完整考试课程、完整 PWA、自定义课程编辑器、管理员后台及社交功能。

AI 前端入口保持暂停；保留后端实现不等于承诺恢复界面或新增服务。
