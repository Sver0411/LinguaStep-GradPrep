# 每日计划

## 生成时机

- Provider 完成数据加载后检查本地日期；当天没有计划才生成并保存。
- 页面保持打开跨过午夜时，每分钟检查一次日期并为新的一天补建计划。
- 刷新和多标签页不会为同一天追加第二份计划；日期是唯一主键。
- 设置页允许按当前配置手动重算今日计划。

## 计划组成

1. 选择默认学习模式尚未学习的新词。
2. 收集今天结束前到期的单词，按复习紧迫度排序并受每日上限控制。
3. 标出早于今日零点的逾期词。
4. 错题优先开启时，按优先级和最近答错时间列出全部活跃错题。
5. 选择尚未学习的语法。
6. 记录每日测试目标题数。

计划完成度只统计能够由 DailyRecord 精确对应的新词、复习词、语法和答题数；错题列表作为优先建议展示，不重复计入分母。

## 自动补足与周末

自动补足开启时，会从最近的历史计划开始收集仍未完成的新词和语法，去重后放到新计划最前，再用内容库中的未学习项目填足。关闭时直接从当前内容库顺序生成。

周六、周日按设置应用系数：

- 轻量：约 70%
- 不变：100%
- 加强：约 130%

数量四舍五入；复习上限和测试目标至少为 1。若可用内容不足，保留真实可用数量，不生成重复占位任务。

## 首页下一步建议

首页根据当前计划依次推荐：逾期/到期复习、新词、语法、测试、活跃错题巩固；全部完成后提供自由学习入口。单词、语法和测试完成页会复用同一套下一步判断，每个任务链接都携带来源或学习模式参数。
