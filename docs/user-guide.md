# 使用指南

[项目首页](../README.md) · [文档目录](README.md) · [内容范围](content.md)

## 当前版本

单词页默认打开上次选择的词书，点击“换书”进入十册书架。进入册内可滚动浏览、搜索和勾选；“顺序背诵”“随机背诵”“背诵所选词”使用相同的五词熟悉与练习流程。详见[词书说明](word-books.md)。

首页展示当前词书与今日任务。独立测试和能力训练入口暂时隐藏，原有文件及答题历史保留；单词学习中的客观熟练度练习继续开放。下文有关独立测试的历史说明仅供恢复功能时参考。

## 先设定自己的节奏

在设置中选择主要目标、学习语言、范围和每日时间预算。可按任务数量学习，也可使用 10 / 20 / 30 分钟预算；考试日期为可选项。

首页的“继续”会接上到期复习、新词、语法及错题。调整设置后可以应用到今日计划，已完成记录会保留。预计用时用于安排学习量，不是考试成绩预测。

## 词卡与五词练习

1. 从首页或单词页开始一轮。三种模式（日语、英语、日英对照）保留各自进度。
2. 每批先熟悉最多 5 组新词。先看中文提示，再按设置同时或分步揭示日语、英语。
3. 熟悉本批后，进入对应选择题。日英模式练日语选英语或英语选日语，单语模式练对应中文。
4. 本轮答对的词退出当前练习池；答错或提前查看答案的词保留。
5. 用新词补满 5 组，只揭示新补入的词，再练习全部保留词和新词。新词不足时按实际数量继续。

例如 5 组通过 3 组、留下 2 组：下一批先揭示 3 组新词，再练“旧 2 组＋新 3 组”。轮次直接衔接，本次全部通过后才出现最终完成页。

“本轮通过”按当前答案判断。长期复习由 FSRS-6 安排；长期“已掌握”还要求隔日成功与记忆稳定性，详见[算法文档](spaced-repetition.md)。

| 快捷键 | 操作 |
| --- | --- |
| `Space` | 揭示或继续；作答反馈后进入下一题 |
| `1`–`4` | 选择 A–D |
| `Esc` | 退出专注模式 |

## 单词、例句与中文朗读

揭示后的两侧单词都显示例句及中文译文，简洁模式也保留。自动朗读顺序为：

- 第一个揭示的表达：单词 → 单词中文释义 → 外语例句 → 例句中文译文。
- 第二个表达：单词 → 外语例句 → 例句中文译文。

例句旁的喇叭可重播“外语例句＋中文译文”。可在设置中关闭自动朗读，保留手动播放。选择题作答前隐藏例句，提交后才展示。

当前使用 Edge 在线神经语音：日语 Nanami、英语 Jenny、中文 Xiaoxiao。需要网络；失败时可重试，不会自动换成系统机械音。自行导入的词若缺例句译文，会如实提示，不用单词义项冒充整句翻译。

## 语法、能力训练和错题

- 语法记住上次选册，点击“切换”选择蓝宝书 N1–N5 或英语。目录按需展开，支持搜索；学习设置中可切换顺序／随机和每轮数量。
- 先读原文讲解、接续、例句和图表，再做“原句填空”；例句按钮连读外语及中文。无可靠填空的条目点“完成阅读”，不计为答题正确。详见[语法来源与审核](grammar-sources.md)。
- 独立测试与能力训练入口暂停，保留原实现和历史记录。
- 听写忽略标点、空格和英语大小写；填空按参考答案判断，未覆盖所有等价表达。
- 答错进入错题本。听力错题保留音频，输入题保留输入作答方式；客观词汇错题再次作答也更新复习记忆。

题目来源及等级范围见[内容说明](content.md)。

## 查词、收藏与加入学习

核心词库支持中文、日语、读音、英语和例句搜索。高频词分区可查阅词书条目，收藏后也可“加入学习”，进入今日新词和后续复习；重复加入会识别已有词并保留进度。

资料页提供五十音及日常日语速查。单纯查阅资料不会增加学习次数。

## 看懂统计

统计区分学习量、首次作答、隔日选择正确率和历史自评回忆。隔日指标要求至少相隔 24 小时，同词同模式每天只计首条；没有历史时显示等待数据，不补造成功记录。

日英词汇识别、听力、阅读和输出能力需要分别练习，不能用一个总正确率代替全部能力。

## 备份和换设备

学习数据保存在当前浏览器的 IndexedDB；桌面布局和手机布局使用同一套数据模型，不代表不同设备会自动同步。

1. 在电脑或手机的设置中导出 JSON 备份，保存到可找回的位置。
2. 换设备或浏览器后，在设置中导入文件。
3. 检查文件并确认后，备份会替换当前设备的数据；需要保留当前记录时先导出。

清理浏览器数据、切换浏览器或隐私模式可能导致读不到原来的进度。存储降级提示出现时，本次记录可能仅保留在页面会话中，应及时导出备份。
